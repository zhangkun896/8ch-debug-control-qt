# 8通道调试控制系统

基于 PyQt5 的 8 通道调试控制桌面程序，用于通过串口与下位机通信、下发通道参数并实时接收上报数据。

## 功能

- 8 通道调试面板：通道数值输入、步进调节、锁定/可调
- 全局数值设置：通道名称、最大值、最小值、步长
- 模式管理：多模式配置（一级/二级/三级菜单），每通道锁定规则与限值
- 串口通信：自动扫描串口、波特率可选、后台线程收发
- 实时监控：下位机上报参数显示 + 原始接收日志
- 指令模板：支持自定义下发指令格式（默认 `SET CH{n}={val}\n`）

## 环境要求

- Windows
- Python 3.12+
- PyQt5、pyserial（见 requirements.txt）

## 安装与运行

双击 `安装依赖.bat` 安装依赖（自动创建虚拟环境），然后双击 `启动程序.bat` 启动。

或手动执行：

```bat
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
venv\Scripts\python.exe main.py
```

## 使用说明

1. 顶部选择串口和波特率，点击「连接」
2. 「前台 → 调试面板」中输入各通道数值，点击「一键下发」
3. 「前台 → 全局数值设置」中配置通道名称与限值
4. 「后台」中新建/编辑/删除模式，配置每通道的锁定规则与限值
